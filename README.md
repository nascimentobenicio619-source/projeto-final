# projeto-final
Esse bot é um joguinho de perguntas, tipo um quiz! Ele pode ser sobre futebol, anime, jogos ou filmes e outros
 
Quando a pessoa chamar o bot, ele sorteia perguntas aleatórias para o jogador responder. A cada resposta certa, o jogador ganha pontos, e no final ele mostra o resultado com a pontuação total!
 
Para funcionar usamos o Python com a biblioteca  discord.py  para ele se conectar no Discord, o módulo  random  para sortear as perguntas e um sistema para guardar e calcular a pontuação de cada jogador
